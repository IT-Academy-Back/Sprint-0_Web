# Exercici 2 · Donar estil a les llistes

## Reutilitza

L'exercici **"Els meus hobbies"**.

## Objectiu

Treballar amb marges i separacions.

## Requisits

- Afegir un color de fons a cada secció.
- Posar espais interiors i exteriors.
- Afegir una vora a les llistes.
- Ressaltar els títols.

## Conceptes

- `margin`
- `padding`
- `border`
- `font-weight`

### Documentació recomanada

- [CSS model de caixes](https://www.w3schools.com/css/css_boxmodel.asp)
