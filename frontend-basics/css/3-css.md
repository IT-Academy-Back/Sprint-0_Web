# Exercici 3 · Guia turística atractiva

## Reutilitza

La **Guia turística d'una ciutat**.

## Objectiu

Millorar l'aspecte visual de la pàgina.

## Requisits

- Afegir una capçalera amb color de fons.
- Ajustar l'amplada de les imatges.
- Arrodonir les cantonades de les imatges.
- Afegir espai entre seccions.
- Aplicar una paleta de colors coherent.

## Conceptes

- `width`
- `border-radius`
- `margin`
- `padding`
- Colors
