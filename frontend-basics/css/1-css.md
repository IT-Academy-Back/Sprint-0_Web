# Exercici 1 · Els meus primers estils

## Reutilitza

La pàgina creada a **"La meva primera pàgina web"**.

## Objectiu

Aprendre a aplicar estils bàsics.

## Requisits

- Canviar el color del títol principal.
- Modificar el tipus de lletra.
- Augmentar la mida del títol.
- Canviar el color de fons de la pàgina.
- Centrar el títol principal.

## Conceptes

- `color`
- `background-color`
- `font-family`
- `font-size`
- `text-align`
