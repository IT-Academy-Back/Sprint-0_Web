# CSS

CSS (*Cascading Style Sheets*) és el llenguatge utilitzat per definir l'aparença i la presentació de les pàgines web. Permet controlar aspectes com els colors, les tipografies, els espais, les mides i la disposició dels elements, fent possible crear interfícies atractives, accessibles i adaptades a diferents dispositius.

Gràcies a CSS, és possible separar el contingut de la seva presentació, fet que facilita el manteniment i la reutilització del codi. Juntament amb HTML i JavaScript, constitueix una de les tecnologies fonamentals del desenvolupament web modern.

---
## Bones pràctiques

Per mantenir el codi més organitzat i fàcil de mantenir, és recomanable separar l'estructura (HTML) de l'estil (CSS). Per aquest motiu, els estils s'han de definir en un fitxer extern (`styles.css`) i enllaçar-lo des de l'arxiu HTML mitjançant l'etiqueta `<link>`, evitant l'ús d'estils en línia sempre que sigui possible.

## Estructura mínima recomanada

```text
frontend/
├── index.html
└── styles.css
```
