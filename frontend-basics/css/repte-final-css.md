# Repte final · Web d'una acadèmia

## Reutilitza

La web creada a HTML.

## Objectiu

Combinar tots els coneixements adquirits.

## Requisits

La web ha de tenir:

- Barra de navegació.
- Capçalera principal.
- Seccions diferenciades.
- Taules de preus.
- Formulari de contacte.
- Colors coherents.
- Botons amb efectes `hover`.

## Conceptes treballats

- Box Model
- Flexbox
- Pseudoclasses
- Organització del CSS

- [CSS Flexbox](https://www.w3schools.com/css/css3_flexbox.asp)
