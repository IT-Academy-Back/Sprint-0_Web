# Exercici 5 · Portafolis personal responsive

## Reutilitza

El portafolis de l'exercici d'HTML.

## Objectiu

Introduir Flexbox.

## Requisits

- Crear una capçalera amb foto i informació.
- Organitzar les seccions utilitzant Flexbox.
- Mostrar els projectes en forma de targetes.
- Afegir efectes en passar el ratolí.
- Fer que la pàgina s'adapti correctament a pantalles petites.

## Conceptes

- `display: flex`
- `justify-content`
- `align-items`
- `gap`
- `hover`
- `flex-wrap`

### Documentació recomanada

- [CSS Flexbox](https://www.w3schools.com/css/css3_flexbox.asp)
