# Exercici 4 · Millorar la carta del restaurant

## Reutilitza

La carta creada en HTML.

## Objectiu

Aprendre a donar estil a les taules.

## Requisits

- Aplicar colors a l'encapçalament.
- Afegir vores a la taula.
- Centrar el text.
- Augmentar l'espai interior de les cel·les.
- Assignar classes a algunes files i donar-los un estil diferent.

## Conceptes

- Selectors d'etiqueta (`table`, `th`, `td`)
- Selectors de classe
- Vores
- Colors
- Espai interior (`padding`)
- Alineació de text (`text-align`)
