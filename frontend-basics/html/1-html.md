# Exercici 1 · La meva primera pàgina web

## Objectiu

Conèixer l'estructura mínima d'un document HTML.

## Requisits

Crea una pàgina web sobre tu mateix que contingui:

- Un títol principal amb el teu nom.
- Un subtítol amb la teva professió o estudis.
- Dos paràgrafs explicant qui ets.
- Una línia horitzontal per separar continguts.
- Un text en negreta.
- Un text en cursiva.
