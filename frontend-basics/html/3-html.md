# Exercici 3 · Guia turística d'una ciutat

## Objectiu

Practicar encapçalaments i organització del contingut.

## Requisits

Escull una ciutat i crea una pàgina amb:

- Títol principal.
- Introducció.
- Tres llocs d'interès.
- Una descripció per a cada lloc.
- Una imatge de cada lloc.
- Un enllaç a una pàgina oficial de turisme.

- [HTML enllaços](https://www.w3schools.com/html/html_links.asp)
