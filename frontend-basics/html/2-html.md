# Exercici 2 · Els meus hobbies

## Objectiu

Aprendre a treballar amb llistes.

## Requisits

Crea una pàgina que contingui:

### Secció "Els meus hobbies"

Una llista desordenada amb:

- Videojocs
- Música
- Esport
- Lectura
- Cinema

### Secció "Top 5 pel·lícules"

Una llista ordenada amb les teves cinc pel·lícules preferides.

## Extra

Afegeix una breu descripció sota cada secció.

- [HTML llistes](https://www.w3schools.com/html/html_lists.asp)
