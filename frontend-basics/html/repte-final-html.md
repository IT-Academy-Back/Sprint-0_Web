# Mini repte final · La web d'una acadèmia

Crear una pàgina web per promocionar una acadèmia de programació.

## Ha de contenir

- Logotip
- Descripció
- Llista de cursos
- Taula de preus
- Formulari de contacte
- Imatges
- Enllaços

### Documentació recomanada

- [HTML formularis](https://www.w3schools.com/html/html_forms.asp)
- [HTML inputs](https://www.w3schools.com/html/html_form_input_types.asp)
