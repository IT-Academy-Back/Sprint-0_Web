
# HTML

## Què és HTML?

HTML (*HyperText Markup Language*) és el llenguatge estàndard que permet estructurar el contingut de les pàgines web.

Defineix elements com:

* Títols
* Paràgrafs
* Imatges
* Enllaços
* Taules
* Formularis

Actua com l'esquelet de qualsevol aplicació web, proporcionant l'estructura que els navegadors interpreten i mostren als usuaris.

Sense HTML, els navegadors no podrien presentar la informació de manera organitzada. A més, constitueix la base sobre la qual treballen:

* **CSS**, encarregat de l'aparença visual.
* **JavaScript**, responsable de la interactivitat.

Per aquest motiu, HTML és una de les tecnologies fonamentals del desenvolupament web.
