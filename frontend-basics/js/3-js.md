# Exercici 3 · Manipular el DOM

## Reutilitza

**"Guia turística"**

## Objectiu

Modificar la pàgina des de JavaScript.

## Requisits

- Amagar i mostrar una imatge.
- Canviar el text d'un títol.
- Afegir una nova secció de forma dinàmica.
- Eliminar una secció.

## Conceptes

- `textContent`
- `style`
- `createElement()`
- `append()`
- `remove()`
