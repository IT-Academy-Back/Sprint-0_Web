# Repte final · Web d'una acadèmia interactiva

## Reutilitza

La web creada a HTML i CSS.

## Requisits

### Cursos

- Botó per mostrar o ocultar la informació dels cursos.

### Preguntes freqüents

- Sistema d'acordió.

### Formulari

- Validació de camps obligatoris.

### Tema clar/fosc

- Botó que canviï l'aspecte de la pàgina.

### Comptador

- Mostrar el nombre total de cursos disponibles.

## Conceptes treballats

- Variables
- Funcions
- Condicionals
- Arrays
- Events
- DOM
- Manipulació d'elements
