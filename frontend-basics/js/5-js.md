# Exercici 5 · Llista de tasques

## Objectiu

Treballar amb arrays i manipulació del DOM.

## Requisits

Permetre:

- Afegir tasques.
- Mostrar-les en pantalla.
- Eliminar una tasca.
- Mostrar quantes tasques hi ha.

- Bucles
- `createElement()`
- Events
