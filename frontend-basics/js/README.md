# JavaScript

## Què és JavaScript?

JavaScript és el llenguatge de programació que aporta interactivitat i dinamisme a les aplicacions web.

Permet:

* Respondre a les accions de l'usuari
* Validar formularis
* Modificar el contingut de la pàgina en temps real
* Gestionar esdeveniments
* Comunicar-se amb servidors per obtenir o enviar dades

Actualment, JavaScript és una tecnologia essencial tant en el desenvolupament **frontend** com **backend**, gràcies a entorns com **Node.js** i a frameworks i biblioteques com **React**, **Angular** o **Vue**.

Juntament amb **HTML** i **CSS**, forma la base sobre la qual es construeixen les aplicacions web modernes.

---
## Bones pràctiques

Per mantenir el codi més organitzat i fàcil de mantenir, és recomanable separar l'estructura (HTML), l'estil (CSS) i la lògica (JavaScript). Per aquest motiu, el codi JavaScript s'ha de definir en un fitxer extern (`script.js`) i enllaçar-lo des de l'arxiu HTML mitjançant l'etiqueta `<script>`, evitant escriure codi JavaScript directament dins del document HTML sempre que sigui possible.

## Estructura mínima recomanada

```text
frontend/
├── index.html
├── styles.css
└── script.js
```
