# Exercici 4 · Formulari de contacte

## Reutilitza

**"Web de l'acadèmia"**

## Objectiu

Capturar informació introduïda per l'usuari.

## Requisits

Crear un formulari amb:

- Nom
- Correu electrònic
- Missatge

Quan es premi el botó:

- Validar que els camps no estiguin buits.
- Mostrar un missatge de confirmació.
- Netejar el formulari.

## Conceptes

- `value`
- `if`
- Funcions
- `.reset()`
