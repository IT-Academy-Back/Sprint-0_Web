# Introducció al desenvolupament frontend

Després d'haver descobert que existeixen diferents llenguatges de programació i que alguns s'utilitzen principalment per al desenvolupament de **frontend** i altres per al desenvolupament de **backend**, és el moment de centrar-nos en la part visible de les aplicacions web.

En aquest bloc treballarem les tecnologies bàsiques del desenvolupament frontend:

## HTML

Permet definir l'estructura i el contingut d'una pàgina web.

## CSS

Permet donar estil i millorar l'aparença dels elements de la pàgina.

## JavaScript

Permet afegir interactivitat i comportament a les aplicacions web.

## Objectiu del bloc

L'objectiu no és dominar aquestes tecnologies, sinó tenir una primera presa de contacte amb el desenvolupament frontend, entendre el paper de cadascuna d'elles i descobrir si és un àmbit que us resulta interessant.

---

## Punt de control

Abans de passar al bloc d'algoritmia, hauries de poder explicar:

- Quin paper té l'HTML en una pàgina web.
- Quin paper té el CSS.
- Quin paper té JavaScript.
- Com es connecten HTML, CSS i JavaScript dins d'un projecte senzill.
- Quina diferència hi ha entre estructura, estil i comportament.
- Quina part del frontend t'ha resultat més clara i quina t'ha costat més.
