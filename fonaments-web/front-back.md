# Desenvolupament frontend vs backend

### Què fa un programador Frontend?

El programador Frontend és el responsable de la part visual d’una aplicació web, és a dir, de tot allò que veu i amb què interactua l’usuari.

Algunes de les seves tasques són:

- Crear la interfície de la web o aplicació.
- Fer que la pàgina sigui responsive i funcioni en diferents dispositius.
- Gestionar les interaccions amb l’usuari (botons, formularis, menús, etc.).
- Consumir les dades proporcionades pel Backend.
- Aplicar la lògica necessària perquè la informació es mostri correctament i les funcionalitats de la interfície funcionin de manera adequada.

Les tecnologies més habituals són HTML, CSS, JavaScript i TypeScript, així com els frameworks Angular o React.

### Què fa un programador Backend?

El programador Backend és el responsable de la lògica i del funcionament intern de l’aplicació. És la part que l’usuari no veu, però que fa possible que tot funcioni correctament.

Algunes de les seves tasques són:

- Implementar la lògica de negoci de l’aplicació.
- Gestionar les bases de dades.
- Crear APIs perquè el Frontend pugui obtenir i enviar informació.
- Gestionar la seguretat, autenticació i permisos dels usuaris.
- Integrar serveis externs i garantir el correcte funcionament del sistema.

Les tecnologies més habituals són Java, PHP, Spring, Laravel, NodeJS, MySQL o MongoDB.

### Com treballen junts?

En una aplicació web, el Frontend i el Backend treballen conjuntament:

1. L’usuari interactua amb la interfície creada pel Frontend.
2. El Frontend envia una petició al Backend.
3. El Backend processa la informació i consulta les bases de dades si és necessari.
4. El Backend retorna una resposta.
5. El Frontend mostra la informació a l’usuari.

Tots dos perfils són igualment importants i, en els projectes reals, treballen de manera coordinada per construir aplicacions completes.
