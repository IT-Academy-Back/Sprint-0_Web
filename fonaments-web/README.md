# Fonaments de la Web

## Objectius

En aquest bloc farem una primera aproximació a com funciona la web.

L'objectiu no és programar encara, sinó entendre les peces bàsiques que intervenen quan obrim una pàgina o fem servir una aplicació web.

En acabar aquest bloc hauràs de poder explicar:

- què és una aplicació web,
- què és el model client-servidor,
- què fa el navegador,
- què són frontend i backend,
- què és una URL,
- què és una request i una response,
- què és una API,
- què és JSON,
- com observar una web amb DevTools.

---

## Presentacions

Aquestes presentacions introdueixen els conceptes bàsics abans de començar amb HTML, CSS, JavaScript i backend.

### 1. [Arquitectura client-servidor](./presentacions/arquitectura-client-servidor.pptx)

Presenta el model bàsic de comunicació entre navegador i servidor, i introdueix les idees de request, response i HTTP.

Conceptes principals:

- client,
- servidor,
- navegador,
- request,
- response,
- HTTP.

### 2. [Anatomia d'una URL](./presentacions/anatomia-url.pptx)

Explica les parts principals d'una URL i com el navegador les utilitza per arribar a un recurs web.

Conceptes principals:

- protocol,
- domini,
- ruta,
- paràmetres de consulta,
- fragments,
- ports.

### 3. [Estructura d'un projecte web](./presentacions/estructura-projecte-web.pptx)

Mostra com s'organitzen els fitxers i carpetes habituals d'un projecte web senzill.

Conceptes principals:

- fitxers HTML,
- fitxers CSS,
- fitxers JavaScript,
- recursos,
- carpetes habituals,
- separació entre frontend i backend.

### 4. Desenvolupament frontend vs backend

Material:

- [Desenvolupament frontend vs backend](./front-back.md)

Conceptes principals:

- què fa el frontend,
- què fa el backend,
- com es comuniquen,
- quines tecnologies s'utilitzen.
