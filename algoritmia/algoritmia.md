# warm-up-exercises

**Descripció**

A l'apartat anterior t'has pogut començar a familiaritzar amb eines bàsiques de frontend. Ara es tracta de tornar a llenguatges de lògica pura (com el llenguatge Python que vas veure a fonaments) però, en particular, en els 2 llenguatges principals de les especialitats backend/fullstack.

JAVA i PHP. Resol els problemes en els 2 llenguatges i treu les teves pròpies conclusions sobre les diferències entre els dos.

### Exercici 1

L'usuari introdueix un número, si el número és positiu, el programa escriu tots els nombres de 0 a aquest nombre positiu, d'un en un. Si el número és negatiu, el programa escriu tots els nombres des de d'aquest nombre negatiu fins a 0. També d'un en un.

Exemple:  
Si entra "3" el programa ha de tornar "1 2 3"  
Si entra "-4" el programa ha de tronar "-4 -3 -2 -1"  

### Exercici 2

Determinar si una contrasenya:  
    - Té almenys 8 caràcters.  
    - Conté una majúscula.  
    - Conté un número.  

Al finalitzar mostrar si la contrasenya és correcte o si no ho és, mostrar quines condicions no compleix.

### Exercici 3

Donat un array de temperatures, digues:  
    - Temperatura màxima  
    - Temperatura mínima  
    - Temperatura mitjana  
    - Dies amb més de 20 graus  

Exemple: [17, 19, 18, 21, 20, 17, 19, 20, 21, 24, 26, 25, 20, 18, 19, 17, 22, 20, 25, 28, 25]  
    - Temperatura màxima = 28  
    - Temperatura mínima = 17  
    - Temperatura mitjana = 21  
    - Dies amb més de 20 graus = 9  

### Exercici 4

En aquest programa farem 2 funcions. Cadascuna d'aquestes funcions tindrà com a paràmetre un string.  
    - La primera funció detectarà si un string és un heterograma(cap lletra es repeteix) com per exemple "residu" o "brou".      
    - La segona funció detectarà si un string és un isograma, és a dir, que en una mateixa paraula les lletres que apareixen, ho fan el mateix nombre de cops. Per exemple: "mama" o "papa".      

### Exercici 5

Mitjançant programació orientada a objectes, tracta de crear una agenda de contactes. Cada contacte tindrà:  
    - Nom  
    - Cognoms  
    - Nº telèfon  
    - Email  
A l'agenda podrem afegir contactes nous, veure un contacte introduint nom i cognoms, i veure tots els contactes enregistrats.  

### Bonus track!(Opcional)

Fes una funció que, donat un array d’elements i un nombre, ens retorni l'array rotant cap a l’esquerra els elements de l'array tantes posicions com indiquem al nombre.  

Exemple:  
Si entra [27,21,2] y 1, el resultat serà [21,2,27]    
Si entra [14,3,5] y 3, el resultat serà [14,3,5]  

L'array pot ser de qualsevol mena de dada.
