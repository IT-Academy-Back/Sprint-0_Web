# Algoritmia

## Objectius

En aquest bloc tornaràs a treballar la lògica de programació, però ara amb dos llenguatges habituals en el desenvolupament backend: **Java** i **PHP**.

L'objectiu no és dominar els dos llenguatges, sinó practicar conceptes que ja coneixes i veure com canvia la sintaxi segons la tecnologia.

En acabar aquest bloc hauràs de poder:

- escriure programes senzills en Java i PHP,
- treballar amb variables, condicionals, bucles i arrays,
- crear mètodes o funcions simples,
- comparar com es resol un mateix problema en dos llenguatges diferents,
- preparar-te per al repte final de backend.

## Punt de control

Abans de passar al repte final, hauries de poder explicar:

- Quines diferències bàsiques has vist entre Java i PHP.
- Com declares variables en cada llenguatge.
- Com escrius condicionals i bucles.
- Com treballes amb arrays.
- Com crees una funció o mètode simple.
- Quin llenguatge t'ha resultat més còmode i per què.
